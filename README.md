# Tech Quiz Testing Configuration

## This is a demonstration of basic cypress testing configuration as applied to a given tech quiz app.

## Description

"This project provides both component and e2e testing via cypress. The quiz app itself is built in a MERN stack and was supplied by the EDX bootcamp."



- The Problem I hope to solve: The tech quiz lacks proper testing.

- The way I hope to solve it: By configuring cypress tests for the front and back end.

- Solving this problem was difficult for the following reasons: Cypress testing syntax was difficult to learn, but useful.

- I learned the following: Cypress testing configuration and minor mongoose skills.

## Usage

tutorial video (here)[https://youtu.be/srN4yHFSGNQ]

this project uses cypress to run tests on a locally hosted interactive site.
    to test, first run the app using 'npm run start'.
    in a separate terminal, use 'npm run cypress' to begin testing.
    launch cypress, and navigate to the quiz section of either testing method to see test results.
